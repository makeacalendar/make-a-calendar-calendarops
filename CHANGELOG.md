# Changelog

## 0.1.0 — initial experimental implementation

- Add date-only Gregorian calendar geometry and ISO week/year values.
- Add modern US observed holidays, configurable business-day range endpoints, retail fiscal weeks, payroll dates, and named shift cycles.
- Add REST API, preview dashboard, month SVG and holiday ICS exports, and JSON/CSV/SVG/ICS CLI reports.
- Add API, jobs, and umbrella Helm charts with secure pod defaults.
- Add CI, container scan/publication, Helm release, and documentation publishing workflows.

This initial version has not yet passed local Go/Helm/cluster verification in the originating environment. Do not infer production readiness from the version number.
