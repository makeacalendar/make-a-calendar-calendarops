# Developer resources

Start with [getting started](getting-started.md), then refer to the [API reference](api-reference.md), [date engine](date-engine.md), [business-day rules](business-day-engine.md), and [fiscal 4-4-5 policy](fiscal-445.md). Deployment information is in [Kubernetes deployment](kubernetes-deployment.md); the chart-specific configuration tables are in each chart README.

Complementary browser tools from Make a Calendar:

- [Monthly calendars](https://make-a-calendar.com/monthly-calendars) for editable printable month layouts.
- [Date tools](https://make-a-calendar.com/date-tools) for one-off date and week calculations.
- [Business-day calculator](https://make-a-calendar.com/business-days-calculator) for manual range comparisons.
- [4-4-5 retail calendar](https://make-a-calendar.com/445-calendar) for retail planning.
- [Pay-period calendar](https://make-a-calendar.com/pay-period-calendar) for payroll dates.
- [Shift calendar](https://make-a-calendar.com/shift-calendar) for rotating-duty visualization.
- [iCalendar generator](https://make-a-calendar.com/ical-generator) for browser-based ICS creation.

CalendarOps uses its own Go implementation. It does not scrape these pages or require the website to remain online.
